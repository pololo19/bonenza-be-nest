# bonenza-be-nest
[Nest](https://github.com/nestjs/nest) framework TypeScript

## Installation

```bash
$ npm install
```
## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Env

```bash

SERVER_NAME=
ENVIRONMENT_KEY=

# Backend Port
PORT=

JWT_SECRET_KEY=
JWT_TOKEN_EXPIRE=

# Config PostgreSQL
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_USER=postgres
POSTGRES_PASSWORD=123
POSTGRES_DATABASE=bonenza

# Frontend URL
WEBSITE_ORIGIN=http://localhost:3000

# Admin URL
WEBSITE_ADMIN=http://localhost:3001

```
